# Changelog

## 1.1.0

- Environment defaults through `GRILLSAY_CHARACTERS`, with CLI overrides.
- Single-character aliases `-c` and `--character`.
- Terminal-aware bubble width and explicit `--width`.
- Unicode display-column wrapping and optional character accent colors.
- Labeled gallery and topic discovery commands.
- 224 new quotes, bringing the built-in total to 470; all quotes tagged by
  topic.
- Weighted character selection and topic-filtered quote selection.
- Optional persisted repeat avoidance with configurable history location.
- Runtime character packs, validation, and a Barista example.
- Cross-platform CI, compiled-executable smoke tests, tagged releases, and
  checksums.
